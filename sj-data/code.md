# 总的目标

* 分析我提供的网页游戏网址，并提供1个python脚本，python脚本用于抓取：<https://sjh5cdn2.good321.net/resgood/index.html?subchannel=merchant1> 网页的所有数据。

# 脚本详细规则

* 不往网页植入会影响网页功能的任何插件
* 启动脚本后自动打开一个谷歌浏览器窗口，宽度 800 高度 1280 DPI 320
* 启动脚本后立即抓取所有的数据包以及资源文件并按照文件类型存放到根目录 /data 目录下
* 脚本所有抓取的文件以及数据实时写入本地磁盘，不缓存
* 如果缺少对应python环境，则自动在项目根目录创建虚拟环境并安装
* 编写一个脚本使用手册命名为readme.md，并且脚本每次更新或者有什么改动都自动更新该文件。
